PATHLY PRIVACY

Your journey data, used with purpose.

This summary describes the Pathly MVP. Last updated September 5, 2026.

Do not upload or enter sensitive data.

For evidence references, use a public portfolio link or a short note. Avoid identity documents, ID numbers, internal documents, home addresses, confidential grades, or files containing other people's data.

01

Data we store

Email and account identity, education profile, selected experience, career target, skill levels, reference categories and notes, reflection responses, roadmap, and task progress.

02

How we use it

Data is used to save each account's journey, calculate skill alignment, set priorities, display past results, and track progress. Evidence references do not increase your score.

03

Storage and access

Authentication and the database use Supabase. Row Level Security restricts journey data to the signed-in user. The browser also keeps a local cache, which is cleared when the account changes or the journey is reset.

04

References are not verification

Pathly records reference categories and notes. It does not open, validate, or guarantee the authenticity of any linked document or website.

05

Your choices

The Reset Journey action deletes targets, assessments, reflections, roadmaps, and progress, while keeping your account and education profile. Self-service account deletion is not yet available in the MVP; contact the Pathly team through the repository to request it.

06

MVP limitations

Pathly does not currently include automated document checks, third-party behavioral analytics, or features for selling user data. This policy should be reviewed before wider public use.
